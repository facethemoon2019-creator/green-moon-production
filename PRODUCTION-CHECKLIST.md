- [ ] D1 migration applied
- [ ] ADMIN_TOKEN secret set

- [ ] Flash offers wired to /api/admin/flash-offers
- [ ] Reviews moderation wired to /api/admin/reviews
- [ ] Order WhatsApp integration configured
- [ ] End-to-end tests passed
